Full guide

Quick start
  1. Open the Scenes tab on the right and click a scene. Space voyage is a good first one.
  2. Press the play button under the preview (or the Space key) to watch it with sound.
  3. Change the code in the Scene editor below the preview. The preview updates by itself a moment after you stop typing.
  4. Open the Helpers tab and click an item to insert it where your cursor is in the editor.
  5. When you're happy, click Record video. Use Save project any time to keep your work.
The preview and timeline
  • Under the preview: play or pause, restart (↺), −f and +f to step one frame, PNG to save the current frame as an image, and the slider to jump to any time.
  • Scene length can be 3 to 180 seconds.
  • Canvas: choose 16:9 for YouTube and widescreen, or 9:16 for Shorts, Reels and TikTok.
  • Mode: 2D Canvas, or 3D (Three.js). 3D needs an internet connection the first time it loads.
Writing a scene

Your code runs once for every frame. The current time in seconds is t. Base everything on t, so jumping around the timeline and recording both work. Don't use timers or your own counters.

Variables you can use: ctx (canvas drawing), t, W and H (canvas size), h (helpers such as h.text and h.circle), dur (scene length), a (sound and voice) and T (3D).

h.bg('#10131a','#27304a');
const p = h.out(h.prog(t, 1, 3));   // goes from 0 to 1 between 1s and 3s
h.circle(h.lerp(-50, W/2, p), H/2, 40, '#ffffff');
h.text('Hello', W/2, H*.2, 54, '#fff', h.win(.4, 4));  // fades in at 0.4s, out by 4s

If something is wrong, a red message appears under the editor with a Go to line button. The preview keeps your code, so just fix it and it recompiles.

Helpers tab

Search or scroll the list and click an item to insert a ready-to-edit line at your cursor. Items under "3D mode only" work only when Mode is set to 3D.

Captions, narration and voice
  • h.caption('text', start, end) shows a subtitle between two times. If Automatically speak scene captions is on in the Voice tab, it is also spoken.
  • a.say(seconds, 'line') speaks a line without showing a caption.
  • Browser voices are free and depend on your device. Google Cloud TTS sounds more natural but needs your own API key with the Text-to-Speech API and billing turned on. Your key is never saved.
  • Preview voice plays the test text. The Narration lines list shows every spoken line in your scene with a Play button.
  • Build scene voice track prepares Google voice audio so it plays with the scene.
  • Recording: Google voice is included automatically. Browser voices are not, unless you tick Capture browser speech in recording and share this tab with audio when your browser asks.
Music, sound and text styling
  • In the Audio tab, upload an audio file, then set volume, start point, fade in, fade out and looping.
  • Sounds made in code (a.tone, a.chord, a.noise, a.kick) take priority over an uploaded file.
  • Mute preview output silences your speakers only. Recordings still contain the audio.
  • Font, text scale and title or caption position apply to all text in the scene.
Using an AI to write scenes
  1. Open the AI prompt tab, pick your AI and a style, and describe what should happen.
  2. Click Copy complete AI prompt and paste it into ChatGPT, Gemini, Claude or another assistant.
  3. Copy the code it returns and paste it into the Scene editor, replacing what is there.
  4. If it shows an error, click Copy fix-my-code prompt, paste that into the AI, and replace your code with its answer.

"Use 3D objects" only changes the prompt. Switch Mode to 3D yourself when the code uses it.

Saving and exporting
  • Autosave: your work is kept in this browser on this computer and restored when you come back. Clearing browser data erases it.
  • Save project makes a .sm file. Use Open project or drag the file onto the page to load it. It stores your code and settings, but not your music file or API key.
  • Record video plays the scene from the start in real time and saves an MP4 if your browser supports it, otherwise WebM. Keep this tab open and visible until it says Saved. Choose Draft, Standard or High quality next to the button.
  • PNG saves a single frame.

Troubleshooting
  • No sound: browsers block sound until you interact. Press play or click the page, and check that Mute preview output is off.
  • Black or empty stage in 3D: 3D needs internet to load Three.js, and the code must use the T helpers. 2D code shows nothing in 3D mode.
  • Google voice fails: check the key, that the Text-to-Speech API is enabled, and that billing is on.
  • Video is WebM, not MP4: your browser doesn't support MP4 recording. Most editors accept WebM, or you can convert it.
  • Want the starter code back: click Reset to preset under the editor.
